Lead List Checker

Free · Honest statuses, never inflated

A lead list is only worth what its emails are worth — so this grades them without lying. Load a raw leads CSV (Company, Website, Contact Name, Title, Email, Phone, City, Category, LinkedIn URL — any of them, in the standard order out). The tool dedupes by email, then company + contact, and grades every address in layers: format first, then whether the domain exists, then whether it publishes a mail server (checked live over DNS-over-HTTPS), then whether it's a role inbox like info@. The best grade it will ever give is “Plausible — syntax + MX pass.” It does not probe mailboxes, so nothing is ever labeled “Verified deliverable” on its say-so. If a lookup itself fails, the row reads “MX check unavailable — not judged,” never a fake dead domain.

The control sample is the studio's 5-row test set: it hits every status class — a plausible personal address, a role account, a malformed address, a dead domain — and drops the planted duplicate (5 in, 4 out). The mail-server check needs a connection (it asks a public DNS resolver); everything else runs on your device, and your file is never uploaded. Results always appear on this page first; the CSV download is a convenience.
