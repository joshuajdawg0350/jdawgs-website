Data Entry Check

Free · Runs on your device · Nothing uploads

Before records go into a client's form, they go through this. Load source records (a CSV keyed from PDFs, images, or an export) and a field spec — the target form's field names, which source column feeds each, whether it's required, and its type (text / email / phone / zip / date / state). The tool splits your records into READY (passes every rule, renamed to the target fields, in target order) and EXCEPTIONS (each with the exact reason it would fail). Values are validated, never rewritten — entry must match the source document.

The sample is the studio's 44-row test file against the sample spec: 39 ready, exactly 5 exceptions — the 5 genuinely bad source rows, each with its reason. Results always appear on this page first; downloads are a convenience. Once loaded, the tool works offline; your file never leaves your device.
