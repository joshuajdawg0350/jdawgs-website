CSV Cleanup & Dedupe

Free · Runs on your device · Nothing uploads

The studio's own cleanup bench, on the shelf. This is the exact tool J-Dawgs Industries runs on client contact lists — the same 8 rules, in the same order. Load a CSV with First Name, Last Name, Email, Phone, City, State, ZIP and Customer Since columns and it comes back cleaned, deduped, and counted. Anything it can't verify gets flagged and blanked — never guessed.

  1. Trim stray whitespace in every field
  2. Title-case first names, last names, and cities
  3. Emails: lowercase, strip stray spaces, validate — failures flagged, never fixed by guessing
  4. Phones: exactly 10 digits (US country code dropped) formatted as (XXX) XXX-XXXX — anything else flagged
  5. States to two-letter codes; ZIP+4 trimmed to ZIP5
  6. Dates rewritten to ISO format (YYYY-MM-DD)
  7. Exact duplicate rows removed
  8. Near-duplicates (same email, or same name + phone) merged, keeping the most complete record

The sample is our published 44-row test file — the cleaned output matches the studio's reference result row for row. Results always appear on this page first; if a download is blocked by your browser, copy the report from the screen. Once this page has loaded, the tool itself works offline — your file never leaves your device either way.
