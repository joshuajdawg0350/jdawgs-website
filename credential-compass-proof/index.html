The misses — verbatim, not buried

Miss 1 — OSEC by-name search link: not found tonight

The Compass sends Missouri electrical-contractor checks to the state OSEC office's "Licensee Search-Active," a by-name public search it cites at pr.mo.gov. When we re-fetched the OSEC page on Mon Nov 16, 2026, that search link was not on the page — the page now leads with the state's MOPRO system. What did verify on the same page: the office's phone, (573) 522-3280, and email, osec@pr.mo.gov. Until the search route is re-verified, treat that one pointer in the tool as stale and use the phone or email. The fix is queued under our Fix-It Guarantee (below).

Miss 2 — EPA 608 "never expires": not re-confirmed tonight

The Compass states that EPA Section 608 certification never expires. In the EPA pages we read tonight (Section 608 Technician Certification, epa.gov), we did not find that sentence to re-confirm it, so the claim is flagged here as not re-confirmed. What EPA's page did confirm in its own words tonight: "EPA does not issue certification cards" — certifying organizations hold the records, which is exactly the tool's "no central EPA lookup" guidance — and EPA lists Type 1, Type 2, and Type 3 certification test topics. The no-expiry line stays flagged until we can cite it from EPA text.

What this tool is — and isn't

Credential Compass is a two-sided credential-verification guide for licensed trade workers and the businesses that check them: what each credential is called, who issued it, where the number is printed, the exact public record to check, the six match fields, and the three honest verdicts (PASS / FAIL / UNCONFIRMABLE = not verified). Deep data covers Missouri only in this version; other states are labeled "not mapped yet" with a general method — no registry is invented. The tool guides and documents a verification; it does not itself query registries or guarantee a credential's status. No account, no ads, everything typed stays on the device.
