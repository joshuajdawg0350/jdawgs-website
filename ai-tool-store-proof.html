How the run worked

Each tool’s own page was loaded in a real browser, fed real sample input, and put through its main action; the output was then checked against what the tool says it produces. Tools that ship with a sample already analyzed were run a second time with changed input, so a “pass” means the tool actually responded to new input — not that a pre-baked answer was sitting on the page. Four results were re-checked by hand in a follow-up pass before this page was published. A tool counted as failed if it produced no output, threw errors instead of results, or — worst case — did not exist at all.
